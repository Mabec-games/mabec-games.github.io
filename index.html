THE MISSION

I build native PC versions of games I love, so they run smoothly on modern hardware without a traditional emulator in the way.

Most projects use static recompilation: the original game code is translated into native C/C++, then extended with widescreen rendering, uncapped framerates, modern controller support and netplay.

You'll need your own legally obtained copy of each game. These projects don't include any game assets.
